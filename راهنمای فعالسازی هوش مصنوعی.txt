راهنمای فعال‌سازی هوش مصنوعی در آیین‌یار پژوهش — نسخه ۰.۲۲.۲
==========================================================

این راهنما برای فعال‌کردن Gemini و OpenRouter داخل افزونه Zotero نوشته شده است.
برای این دو سرویس نیازی به نصب Ollama یا دانلود مدل نیست؛ اما اینترنت و کلید API شخصی لازم است.
API Key یک رمز خصوصی است؛ آن را در گروه‌ها، پیام‌ها، اسکرین‌شات‌ها یا GitHub منتشر نکنید.

قبل از شروع
-------------
۱) Zotero 10 را اجرا کنید و آیین‌یار را از منوی Tools باز کنید.
۲) در منوی افزونه روی «هوش مصنوعی محلی و آنلاین» کلیک کنید.
۳) در بخش «انتخاب موتور هوش مصنوعی»، یکی از Gemini یا OpenRouter را انتخاب کنید.
۴) روبه‌روی فیلد «کلید API اختصاصی» لینک مستقیم دریافت کلید قرار دارد؛ روی آن کلیک کنید تا سایت رسمی باز شود.
۵) کلید دریافت‌شده را در همان فیلد بچسبانید. کلید فقط تا وقتی پنجره آیین‌یار باز است در حافظه نگه داشته می‌شود.

روش اول: Google Gemini
-----------------------
سایت رسمی دریافت کلید: https://aistudio.google.com/api-keys
راهنمای رسمی Google: https://ai.google.dev/gemini-api/docs/api-key

۱) آدرس بالا را در مرورگر باز کنید و با حساب Google خود وارد شوید.
۲) در صورت نمایش قوانین استفاده، آنها را مطالعه و در صورت موافقت تأیید کنید.
۳) وارد بخش API Keys شوید. اگر حساب شما تازه است، ممکن است پروژه پیش‌فرض خودکار ساخته شود.
۴) روی «Create API key» بزنید. اگر از شما پروژه (Project) خواست، یک پروژه موجود را انتخاب کنید.
   اگر پروژه‌ای نمایش داده نمی‌شود، از بخش Projects در AI Studio یک پروژه ایجاد یا یک پروژه Google Cloud موجود را Import کنید و سپس به API Keys برگردید.
۵) کلید ساخته‌شده را Copy کنید. اگر امکان ساخت کلید ندارید، دسترسی آن پروژه را بررسی کنید یا پروژه‌ای بسازید که مالک آن هستید.
۶) به Zotero و صفحه آیین‌یار برگردید؛ دکمه «Gemini · سهمیه رایگان» را انتخاب کنید.
۷) کلید را در فیلد «کلید API اختصاصی» Paste کنید. مدل پیشنهادی موجود در افزونه را انتخاب کنید.
۸) در بخش «تعیین متن پژوهشی» یک چکیده عمومی وارد کنید یا از «خواندن عنوان و چکیده منبع انتخابی» استفاده کنید.
۹) قبل از ارسال، رضایت آگاهانه را فعال کنید و روی «تحلیل با مدل انتخاب‌شده» بزنید.
۱۰) دکمه «بررسی تنظیمات موتور آنلاین» فقط شکل اولیه کلید و تنظیمات را می‌سنجد؛ درست بودن کلید با اولین درخواست واقعی مشخص می‌شود.

روش دوم: OpenRouter
-------------------
سایت رسمی دریافت کلید: https://openrouter.ai/settings/keys
راهنمای رسمی شروع: https://openrouter.ai/docs/quickstart

۱) لینک بالا را باز کنید و با یک حساب OpenRouter وارد شوید یا حساب بسازید.
۲) در صفحه Keys روی «Create Key» (یا «Create API Key») بزنید.
۳) اگر خواست، نامی مثل AyinYar برای کلید بنویسید. تنظیمات محدودیت هزینه و سقف استفاده را با دقت بررسی کنید.
۴) کلید جدید را Copy و در جایی امن نگهداری کنید. کلید را عمومی نکنید.
۵) در افزونه موتور «OpenRouter · مدل رایگان» را انتخاب کنید و کلید را در فیلد API Paste کنید.
۶) مسیر مدل در این نسخه «openrouter/free» است؛ آیین‌یار به‌صورت خودکار مدل پولی انتخاب نمی‌کند.
۷) متن غیرمحرمانه وارد کنید، رضایت ارسال آنلاین را فعال کنید و «تحلیل با مدل انتخاب‌شده» را بزنید.
۸) در حالت رایگان ممکن است مدل یا ارائه‌دهنده پاسخ بین درخواست‌ها تغییر کند یا موقتاً در دسترس نباشد.

بعد از اتصال: گفت‌وگوی چندپیامی
--------------------------------
برای پرسش‌وپاسخ آزاد به بخش «گفت‌وگوی آزاد با هوش مصنوعی» در همین صفحه بروید؛ پرسش خود را بنویسید و «ارسال پیام» را بزنید.
رضایت ارسال داده در بخش ۳ باید فعال باشد. امکان افزودن بخشی از چکیده به‌عنوان زمینه گفت‌وگو نیز اختیاری است.
کلیدها و تاریخچه گفت‌وگو دائمی ذخیره نمی‌شوند و با بستن پنجره از حافظه این پنجره پاک می‌شوند.

رفع خطاهای رایج
---------------
- «کلید API را وارد کن»: کلید کامل را کپی کنید؛ فاصله یا خط جدید ابتدا و انتهای کلید نباشد.
- «401 / 403»: کلید معتبر نیست، منقضی/لغو شده یا دسترسی پروژه/حساب به مدل محدود شده است.
- «429 / Rate limit / Quota»: سهمیه مصرف شده یا تعداد درخواست‌ها زیاد است؛ بعداً تلاش کنید یا سهمیه حساب را بررسی کنید.
- «404 / Model not found»: مدل انتخابی ممکن است تغییر کرده یا در سطح رایگان در دسترس نباشد؛ به فهرست مدل‌های خود افزونه و مستندات سرویس رجوع کنید.
- خطای اتصال: اینترنت، VPN/پروکسی، محدودیت منطقه‌ای و دسترسی به سایت ارائه‌دهنده را بررسی کنید.
- اگر «بررسی تنظیمات» موفق بود ولی تحلیل خطا داد، کلید لزوماً معتبر نیست؛ آن دکمه تماس واقعی با مدل انجام نمی‌دهد.
- تعویض Gemini و OpenRouter کلید قبلی را از فیلد پاک می‌کند؛ برای هر سرویس کلید مخصوص همان سرویس را وارد کنید.

حریم خصوصی و هزینه
------------------
- گرفتن API Key لزوماً به معنی استفاده رایگان نامحدود نیست؛ سهمیه رایگان و شرایط هزینه ممکن است تغییر کند.
- در سطح رایگان Gemini، درخواست‌ها طبق سیاست‌های فعلی Google ممکن است برای بهبود خدمات استفاده شوند.
- در OpenRouter داده‌ها به OpenRouter و ارائه‌دهنده مدل منتخب ارسال می‌شوند؛ سیاست داده ممکن است برای هر ارائه‌دهنده متفاوت باشد.
- مقاله منتشرنشده، پایان‌نامه محرمانه و اطلاعات شخصی را بدون رضایت و بررسی سیاست‌های حریم خصوصی ارسال نکنید.
- هیچ کلید API را برای سازنده یا فرد دیگری ارسال نکنید. اگر کلید افشا شد، فوراً آن را در داشبورد مربوطه لغو کنید و کلید جدید بسازید.
- هوش مصنوعی ممکن است اشتباه کند؛ پاسخ‌ها و استنادها را قبل از استفاده علمی بررسی کنید.
